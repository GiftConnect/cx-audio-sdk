# Security

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential,
privacy defect, or abuse path.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact CX through your existing business or support
channel and include:

- The affected SDK version and platform.
- Reproduction steps or a minimal test case.
- The expected and observed behavior.
- Potential security or privacy impact.
- Any logs with credentials, identifiers, placement values, and user data
  removed.

Please allow the maintainers time to investigate and coordinate a release
before publishing details.
